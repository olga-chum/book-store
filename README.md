# Book_store

«Chapter & Verse» — это дипломный проект по созданию интернет-магазина для продажи книг, разработанный с нуля на Django.
Основные задачи:

✅ Реализация каталога с фильтрацией по жанрам.

✅ Система регистрации и аутентификации пользователей.

✅ Корзина с возможностью оформления заказа и оплаты.

✅ Админ-панель для управления товарами, категориями, заказами и пользователями.

✅ Реализация поисковой строки.

Особенности реализации:
- Backend: Использование Django ORM для работы с PostgreSQL (хранение данных о книгах, заказах, пользователях).
- Frontend: Кастомные стили на SCSS, семантическая верстка, динамическое обновление контента без перезагрузки страницы.
- Безопасность: Защита от SQL-инъекций, CSRF-токены, хеширование паролей.
